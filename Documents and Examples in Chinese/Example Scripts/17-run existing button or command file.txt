# 本示例展示了如何把已经写好的一大段多行命令，直接拿到脚本区域里逐行运行
# 适用场景：按键发送区域里已经有一个调好的按键，或者手上有一个几百行的命令清单txt，
# 现在想让它变成自动化脚本的一部分，但不想把每一行都改写成 send_and_get("...") 的形式

# 示例中使用的函数：
# run_button(按键名, 等待符号, 超时时间) 直接运行按键发送区域里某个已有按键保存的多行内容，行为与点击该按键一致
# send_commands_from_file(文件名, 等待符号, 超时时间) 从一个纯文本文件逐行读取内容并运行，规则与按键发送完全相同
# 两个函数都是有返回值的，每一次等待都成功返回1，有任何一次等待超时返回0，可以配合if进行指定操作
# 某一行超时不会中断整段运行，会在主窗口用红色写一条告警然后继续下一行

show_str("\nexample start\n")

# 运行按键发送区域里名为 init radio 的按键，每条普通命令发送后等待 $ 出现，最多等20秒
run_button("init radio", "$", 20)

# 运行按键，并用返回值判断是否全部成功
ok = run_button("init radio", "$", 20)
if ok:
    show_str("\nall commands got the prompt\n")
if not ok:
    show_str("\nsome commands timed out, check the red alert above\n")

# 如果多个标签页里有同名按键，用 tab_name 参数指定是哪一个
run_button("init radio", "$", 20, tab_name="Tab 1")

# 从txt文件逐行运行。只写文件名时，以界面上【脚本路径】输入框为基准去找该文件
send_commands_from_file("init_cmds.txt", "$", 20)

# 也可以直接写绝对路径，路径前面加 r 可以避免反斜杠被当成转义符
send_commands_from_file(r"D:\my cmds\init_cmds.txt", "$", 20)

show_str("\nexample end\n")


# ============================================================
# 命令清单txt怎么写
# ============================================================
#
# 就是一个纯文本文件，一行一条命令，不需要加引号，不需要加逗号，
# 不需要包装成任何函数。举例，文件内容直接写成下面这样就行：
#
#     # 这是注释行，会被跳过
#     dra r krypton:0 ADC_IF_1_DL_MEAS_LANE_2
#     dra r krypton:0 ADC_IF_1_DL_MEAS_LANE_3
#     wait 2
#     rvc r PaDriverBias0:0
#
# 空行会被跳过，以 # 开头的注释行会被跳过，
# 每一行的行尾空格会被自动去掉，所以命令长短不齐、行尾多了空格都没关系。
# 文件编码支持 utf-8 和 gbk，程序会依次尝试。


# ============================================================
# 每一行是怎么被处理的
# ============================================================
#
# 这两个函数的处理规则和【点击按键发送】完全一致，按下面的顺序判断每一行：
#
#   1. 空行、以 # 开头的注释行                     跳过
#   2. wait <秒>                                   真的等待，不发送到串口
#   3. wait for <字符串> for <秒>                  真的等待，不发送到串口
#   4. 自定义函数命令                              执行，不发送到串口
#   5. 其余内容                                    发送到串口，然后等待符号
#
# 第4条支持的自定义函数命令，与按键发送区域支持的完全相同：
#   show_str("xxx")        show_date_time()
#   set_port("COM3")       set_baudrate(115200)
#   connect_serial()       close_serial()          toggle_serial()
#   open power shell       power shell send xxx    powershell_send("xxx")
#   visa_init(ADDRESS)     visa_query(CMD)         visa_write(CMD)     visa_read()
#
# 另外，发送一条普通命令后，如果下一行是 wait 语句，
# 就跳过本行对等待符号的等待，直接执行那条 wait，避免重复等待。
# 这一点也和按键发送引擎的行为保持一致。
#
# 如果你不希望上面这些解释发生，希望每一行都原样发到串口，
# 加一个 interpret=False 参数：
#
#     run_button("init radio", "$", 20, interpret=False)
#     send_commands_from_file("init_cmds.txt", "$", 20, interpret=False)
#
# 用得上的场合：设备本身有一条叫 wait 的命令，不想被当成等待语句吃掉。


# ============================================================
# 运行时的界面反馈
# ============================================================
#
# 运行期间，脚本行的行尾会显示 (当前行/总行数 剩余秒数)，例如
#
#     run_button("init radio", "$", 20) (12/300 18)
#
# 表示正在跑第12条、一共300条、当前这条还剩18秒超时。
# 遇到 wait 语句时后面那个秒数由 wait 自己的倒计时接管。
#
# 某一行没等到等待符号时，主窗口会用红色写出这样一段，前后各空一行：
#
#     *** 等待超时 ***  来源：按键 init radio（标签页 Tab 1）  第 12 行（进度 12/300）
#         命令：dra r krypton:0 ADC_IF_1_DL_MEAS_LANE_2
#         未等到等待符号：$    超时时间：20 秒
#         已跳过该行的等待，继续执行下一行
#
# 其中的行号是命令清单里的原始行号（含注释和空行一起数），
# 可以直接拿这个行号去txt或按键内容里定位那一条命令。
# 运行中随时可以按暂停和停止，每一行开头都会响应。


# ============================================================
# 不用新增函数的写法
# ============================================================
#
# 脚本区域里可以直接用 Python 的内置函数，比如 open()，os 模块也已经可用。
# 想自己控制每一行的处理时可以这样写，比如只发某一段、或者把每行的回复收集起来解析。
# 注意 gui 指向程序本身，脚本运行在子线程，读界面控件必须套 gui.tk_safe(...)

BASE_DIR = gui.tk_safe(lambda: gui.multi_script_path_entry.get().strip())
FULL_PATH = os.path.join(BASE_DIR, "init_cmds.txt")

for RAW in open(FULL_PATH, encoding="utf-8").read().splitlines():
    CMD = RAW.rstrip()
    if not CMD.strip() or CMD.lstrip().startswith("#"):
        continue
    send_line(CMD)
    if not wait_for("$", 20):
        show_str("timeout on: " + CMD + "\n")

# 需要注意，脚本区域【不支持】三引号多行字符串。
# 脚本在运行前会被逐行处理并插入行高亮调用，多行字符串会被插坏。
# 所以命令清单要放在外部txt里，不要写成脚本里的多行字符串。
